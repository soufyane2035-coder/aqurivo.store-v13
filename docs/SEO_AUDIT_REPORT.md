# تقرير تدقيق SEO — AQURIVO

**تاريخ الفحص:** 2026-10-28  
**النطاق:** فحص الكود والبيانات المتاحة، واختبار عينة من الصفحات المنشورة وملفات الزحف. لم تُجرَ أي تغييرات على روابط الشراء أو `/go/[slug]`، ولم يُحذف محتوى أو تُغيّر عناوين URL.

## الخلاصة

- خريطة الموقع المنشورة صالحة عند فحصها: **299 عنواناً**، بلا عناوين مكررة، وبلا مسارات إدارية أو روابط إحالة أو معاملات، و**242** قيمة `lastmod` مخزنة. الروابط البديلة اللغوية الـ **888** تشير إلى صفحات موجودة ومتبادلة.
- `robots.txt` المنشور متاح ويشير إلى `https://aqurivo.store/sitemap.xml`، مع استبعاد الإدارة والحسابات وواجهات API ومسار التحويل.
- الصفحات الإنجليزية والعربية المفهرسة لها عناوين ووصف وcanonical وبدائل لغوية في metadata. عينة أداة نمو الاستثمار أظهرت عنواناً إنجليزياً وعنواناً عربياً مختلفين، وcanonical منفصلاً لكل لغة.
- رُصد اختلاف فعلي في مسارات التوافق القديمة: `/blog` و`/ar/guides` يقدّمان بيانات تحريرية متقاربة، لكن `/blog` كان يعرض نصاً إنجليزياً مع عنوان ووصف عربيين وcanonical إلى `/ar/guides`. عُدّل تحديد اللغة في هذه المسارات إلى العربية، وأُضيف ضبط مبكر للغة والاتجاه في الصفحة، من دون إعادة توجيه أو تغيير URL.
- فحص HTML المنشور أظهر أن وسم `<html>` في `/ar/...` ما زال يخرج من الخادم بصفة `lang="en" dir="ltr"` قبل تنفيذ JavaScript. أُضيف تصحيح مبكر في `<head>` للمسارات الصريحة والقديمة؛ لكن لا يمكن تأكيد أثره على الإنتاج قبل نشره. كما أن قيمة HTML المرسلة من الخادم لم تتغير، ويظل تحسينها من الخادم عملاً لاحقاً يحتاج موازنة مع أثر جعل تخطيط الجذر ديناميكياً على التخزين المؤقت.
- لم يُتح اتصال أو تفويض إلى Google Search Console في هذه الجلسة؛ لذلك لا توجد بيانات موثقة عن النقرات أو مرات الظهور أو الاستعلامات أو حالة فهرسة Google. لا يُستنتج من وجود الصفحة في sitemap أنها مفهرسة.

## الجرد والأدلة

### أنواع الصفحات

| النوع | المسارات الأساسية | اللغات / الملاحظات |
|---|---|---|
| الصفحة الرئيسية | `/en`، `/ar` | عنوان ووصف وcanonical وhreflang منفصلة. `/` يعيد التوجيه وفق تفضيل الزائر إلى مسار لغة صريح. |
| كتالوج المنتجات | `/[locale]/products`، `/[locale]/products/[slug]` | واجهات عربية وإنجليزية؛ التفاصيل تستخدم بيانات المنتج المنشورة. المسار القديم `/products` ما زال متاحاً ويُعامل كنسخة عربية. |
| الفئات | `/[locale]/categories`، `/[locale]/categories/[slug]` | الفئات النشطة فقط في المصدر؛ أسماء ووصف كل لغة. |
| الأدلة والمراجعات | `/[locale]/guides`، `/[locale]/guides/[slug]` | 32 مقالة منشورة في نسخة البيانات المحلية؛ بيانات عربية وإنجليزية. |
| الأدوات | `/[locale]/tools`، `/[locale]/tools/[slug]` | 11 أداة؛ صفحات مستقلة مع metadata ومحتوى الاستخدام وروابط سياقية إلى الأدلة/الأدوات ذات الصلة. |
| صفحات الفيديو | `/[locale]/videos/[slug]` | 80 عنواناً في sitemap المنشور، مع بيانات VideoObject عند وجود مصدر فيديو صالح. |
| صفحات ثابتة | about، contact، privacy-policy، terms، report، security | مدرجة في sitemap، وmetadata في الصفحات المفحوصة تسمح بالفهرسة. |
| صفحات الشفافية | `/how-it-works`، `/affiliate-disclosure`، `/cookies` | مسارات جذرية مدرجة في sitemap. |
| إدارة ومصادقة وحساب | `/admin`، login/register/account، `/api/...` | مستبعدة من sitemap؛ يقيّدها `robots.txt` عند الحاجة. |
| مسارات توافق قديمة | `/products`، `/categories`، `/guides`، `/blog` | تعيد 200 ولا تعيد التوجيه. بعضها aliases لمحتوى مسارات اللغة؛ لا تُدرج في sitemap، وتُشير metadata إلى المسار العربي المناظر. |

### المحتوى والروابط الأساسية

- نسخة البيانات المحلية `server/data/aqurivostor-data.json` تضم 49 منتجاً منشوراً و32 مقالة منشورة و5 فئات نشطة. في هذه النسخة لا توجد أسماء/ملخصات منتجات أو أجسام مقالات ناقصة لإحدى اللغتين. هذه إحصاءات للنسخة المحلية، وليست ادعاءً بقراءة قاعدة بيانات الإنتاج مباشرة.
- صفحات الأداة المفحوصة (`investment-growth-calculator`) تعرض مدخلات ونتائج وخطوات استخدام وتفسيراً وأسئلة ذات صلة وروابط أدلة. النص العربي ليس ترجمة حرفية كاملة للعناوين الإنجليزية، ويشرح مخرجات التضخم والقوة الشرائية.
- أظهرت قائمة المقالات زوجين محتملين متداخلين حول المنتج نفسه: مراجعتا COSORI Pro LE، ومراجعتا Contigo Byron. التشابه في العنوان والمنتج لا يثبت تكرار المحتوى؛ لم تُدمج الصفحات أو تُحذف ولم تتغير canonicals. يلزم تحرير ومقارنة نصية وبيانات Search Console قبل أي قرار.
- لم يُنفذ زاحف شامل لكل الروابط الداخلية أو تدقيق أداء/صور/مقاييس Core Web Vitals. اختُبرت عينات من المسارات والـ metadata، وليس كل صفحة من أصل 299 عنواناً.

## النتائج حسب الأولوية

### P0 — مانع زحف أو تعارض أساسي

**لا توجد مشكلة P0 مؤكدة في العينة المنشورة.** ملف `robots.txt` وXML sitemap صالحان، وروابط sitemap فريدة، وأهداف alternates موجودة ومتبادلة.

### P1 — مرتفع الأثر

1. **عدم تطابق لغة المسارات القديمة — عولج في الكود، بانتظار نشر واختبار.**  
   الدليل: `/blog` و`/ar/guides` أعادا 200؛ في الفحص الحي كان عنوان `/blog` عربياً وcanonical هو `/ar/guides`، بينما محتوى القائمة المرئي كان إنجليزياً. عُدّل `i18n/routeLocale.ts` و`I18nProvider` لتثبيت المسارات القديمة المعروفة على العربية، وجعل تبديل اللغة ينتقل إلى المسار الإنجليزي الصحيح (`/blog/x` إلى `/en/guides/x`) بدلاً من ترك المحتوى يتبع cookie. أضيف ضبط مبكر لـ `lang/dir` في `app/layout.tsx`. بقي التحقق من DOM بعد النشر.

2. **وسم لغة المستند في HTML المرسل من الخادم — تخفيف جزئي، والتحقق المتبقي واضح.**  
   الدليل: HTML الخام لـ `/ar/tools/investment-growth-calculator` و`/ar/guides` حمل `lang="en" dir="ltr"`، ثم يحدّث `I18nProvider` المستند في العميل. أضيف في `<head>` تصحيح مبكر للمسارات `/ar` و`/en` والمسارات القديمة الأربعة. هذا يحسن DOM قبل عرض المحتوى في المتصفح، لكنه لا يغيّر قيمة الوسم في HTML الخام الذي يرسله الخادم. الإصلاح الكامل من الخادم يتطلب قراراً معمارياً لتوفير locale إلى root layout أو فصل root layouts؛ استدعاء `headers()` في التخطيط الجذري قد يعطّل توليد/تخزين ISR، لذا لم يُنفذ هذا التغيير عالي الأثر دون قياس.

3. **بيانات الأداء والفهرسة غير متاحة.**  
   لا يوجد تكامل Search Console متاح في أدوات الجلسة ولا تم تقديم صلاحية للحساب. لا يمكن تحديد صفحات ذات ظهور مرتفع ونقرات منخفضة أو إثبات الفهرسة/الترتيب. الإجراء التالي هو ربط property `aqurivo.store` وتصدير تقارير الأداء والفهرسة وبيانات الصفحات والاستعلامات.

### P2 — تحسينات محتوى وروابط وتجربة صفحة

1. **منع صفحات غير منشورة أو بدائل لغوية غير موجودة من دخول sitemap — عولج واختُبر.**  
   نُقل بناء الخريطة إلى `lib/seo-sitemap.ts` مع فلاتر مستقلة للحالة المنشورة، والفئات غير المعطلة، ووجود slug. تُستخدم تواريخ `updatedAt/createdAt/publishedAt` المخزنة فقط؛ التاريخ غير الصالح يُحذف ولا يُستبدل بتاريخ اليوم. صفحات الفيديو لا تعلن إلا عن اللغات التي لها مصدر فيديو فعلياً. اختبارات `tests/seo-sitemap.test.ts` تغطي هذه الحالات، وعدم التكرار، ووجود أهداف البدائل.

2. **مراجعة احتمال تداخل مقالات المنتجات.**  
   قارن تحريرياً زوجي COSORI وContigo المذكورين أعلاه، وأضف لكل مقال فرقاً واضحاً في السؤال/الاختيار/المقارنة إن كان ذلك صحيحاً. لا تدمج أو تحذف أو تغيّر canonical قبل مراجعة الزيارات والروابط والطلب.

3. **تعميق الربط السياقي بين مراجعات المنتجات وأدوات القرار.**  
   حافظ على الروابط ذات الصلة الموجودة بين الأدلة والأدوات، وأضف رابطاً إلى أداة “هل يستحق الشراء؟” أو قيمة وقت العمل فقط حين يشرح قرار شراء المنتج فعلاً. لا تضف روابط متكررة آلية لكل الصفحات.

4. **التحقق الشامل من HTML وروابط الصفحة والصور على الهاتف.**  
   فحص العينات أظهر H1 ومحتوى أداة ظاهرين في HTML؛ لم يُنفذ تدقيقاً آلياً كاملاً لعناوين H1 أو alt أو الروابط الداخلية أو أداء الهاتف لكل الصفحات.

### P3 — بيانات/فرص مستقبلية

- تحديث خريطة الكلمات بعد 28–90 يوماً من بيانات Search Console، مع فصل الدول/الأجهزة واللغتين.
- متابعة مؤشرات Core Web Vitals ونتائج Mobile Lighthouse أو CrUX قبل تعديل الصور أو تحميل الخطوط.
- التوسع في صفحات مقارنة/أدلة جديدة فقط بعد وجود استعلام مميز لا تغطيه المقالات الـ32 الحالية ومعلومة أصلية يمكن إضافتها.

## التنفيذ والاختبارات

- تغييرات الكود: `app/sitemap.ts`، `lib/seo-sitemap.ts`، `i18n/routeLocale.ts`، `i18n/I18nProvider.tsx`، `app/layout.tsx`، واختبارات SEO/اللغة.
- `npm test`: **50 اختباراً ناجحاً** في التشغيل الكامل؛ اختبارات SEO المستهدفة نجحت أيضاً بعد آخر تعديل.
- `npm run lint`: نجح؛ إعداد ESLint الحالي لا يوفّر parser/قواعد TypeScript، لذلك استدعاء ESLint المباشر لملفات `.ts/.tsx` يتجاهلها. فُحصت الأنواع بواسطة TypeScript وNext build.
- `npx tsc --noEmit`: نجح بعد إعادة التحقق.
- `npx next build` مع `NODE_ENV=production`: نجح، وبنى 160 صفحة ثابتة. لم يُنشر الناتج.
- الإنتاج: فُحص `robots.txt` وXML sitemap كاملاً باستخدام محلل XML. النتائج: 299 URL، 0 مكررة، 0 هدف hreflang مفقود، 0 زوج لغوي غير متبادل، 242 `lastmod`، و888 رابط alternate. المسارات الستة `/products` و`/ar/products` و`/en/products` و`/blog` و`/ar/guides` و`/en/guides` أعادت HTTP 200 عند الفحص.
- لم يُتحقق من Search Console أو بيانات Google، ولم يُجر تدقيق شامل لكل الروابط/رموز HTTP أو Core Web Vitals. نتائج الإنتاج السابقة تخص النسخة المنشورة الحالية، وليست تحققاً من تغييرات هذا الفرع التي لم تُنشر.
