## 4. رحلة الزائر عند الضغط على الرابط في جوجل (Click-to-Tool Flow)

1. ينقر الباحث في جوجل على النتيجة فينتقل مباشرة إلى `https://aqurivo.store/ar/tools/code-to-image` (أو `/en/tools/code-to-image`).
2. تفتح له فوراً **واجهة استوديو تحويل الكود إلى صورة احترافية** بشعارها الخاص (`CodeToImageLogo`).
3. يلصق الكود ويختار الثيم وحجم الحواف، ثم يحمل الصورة بدقة `2x Retina PNG` أو ينسخها للحافظة بضغطة واحدة.
