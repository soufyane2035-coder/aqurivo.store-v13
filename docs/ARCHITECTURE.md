# الهندسة المعمارية والتقنية لمنظومة AQURIVO (ARCHITECTURE.md)

مرحباً بك يا صديقي في التوثيق الهندسي والمعماري لمنظومة **AQURIVO**. يشرح هذا الملف المبادئ المعمارية للمشروع، هيكل المجلدات، استراتيجية التصيير، نظام التخزين المؤقت فائق السرعة، هندسة الأمان، ونموذج البيانات المشترك.

---

## 1. الركائز المعمارية للمنظومة (Architectural Foundations)

1. **Next.js 15+ App Router:**
   * الاعتماد الكامل على التصيير من جانب الخادم (Server Components) كأساس افتراضي لضمان سرعة التحميل الأولى، تفوق نتائج محركات البحث (SEO)، وحماية بيانات العمليات الحساسة.
   * نقل التفاعلية إلى المكونات الطرفية (Client Leaves) لتقليل حجم حزم JavaScript المرسلة للمتصفح.
2. **انعدام الاعتماد على Tailwind CSS:**
   * استخدام نظام الأنماط الوحدوية (CSS Modules) مدعوماً بملف الرموز المركزية (`tokens.css`) الذي يتحكم في متغيرات الألوان، الخطوط، المسافات، وحواف العناصر.
   * التوافق التام مع الوضعين الفاتح والداكن (Light/Dark Themes) ودعم ثنائية اللغة (RTL/LTR) عبر CSS Logical Properties.
3. **طبقة التخزين المؤقت بالذاكرة الفائقة (In-Memory Micro-Caching):**
   * منع الاستعلامات المتكررة لقاعدة البيانات عبر وحدات تخزين مؤقت داخلية للمنتجات (`products-cache.ts`) والأقسام (`categories-cache.ts`)، مما يقلل زمن الاستجابة إلى الصفر ويوفر استهلاك موارد الخادم بنسبة تزيد عن 90%.
4. **أمان معزول على مستوى الخادم (Zero-Discovery Admin):**
   * عزل تام لمنطقة الإدارة (`/admin`)؛ حيث يتم فحص التوثيق وصلاحيات البريد الإداري على الخادم، وإرجاع صفحة 404 صامتة لأي شخص غير مصرح له دون الكشف عن وجود لوحة التحكم.
5. **محرك التحويل وتتبع الإحالات الآمن (`/go/[slug]`):**
   * حماية خصوصية المشترين بعدم تخزين عناوين IP الخام.
   * استبعاد نقرات الروبوتات وعناكب البحث، وتسجيل النقرات المعتمدة قبل التحويل اللحظي للمتجر الشريك.

## 3. تدفق البيانات والأمان والتخزين المؤقت (Data Flow & Security)

### أ. دورة حياة طلب الزائر (Visitor Request Lifecycle)
1. **الاستقبال والتوجيه:** يمر الطلب عبر Next.js Middleware لتحديد اللغة وإعداد ترويسات الأمان (Security Headers: CSP, HSTS, X-Frame-Options).
2. **فحص الكاش الداخلي:** إذا كان الطلب يستهدف منتجاً أو قسماً، يتم البحث في كاش الذاكرة (`products-cache.ts`). في حال وجوده، يُعاد فوراً في زمن يقل عن 1 مللي ثانية.
3. **التصيير والتوليد:** يقوم الخادم ببناء الصفحة وإرفاق وسوم الـ OpenGraph والـ JSON-LD التلقائية لمحركات البحث.

### ب. دورة التحويل وتتبع الإحالات (`/go/[slug]`)
1. يضغط الزائر على زر الشراء، فيتوجه إلى `/go/[slug]`.
2. يتحقق الخادم من هوية المتصفح: إذا كان عنكبوتاً آلياً (Bot/Crawler)، يتم تحويله دون احتساب النقرة لحماية الإحصائيات.
3. بالنسبة للزائر البشري: تُنشأ تجزئة أحادية الاتجاه (One-Way Hash) باستخدام الملح السري المشفر لمنع التكرار، دون تخزين عنوان IP صريح حفاظاً على خصوصية الزائر وفق لائحة GDPR.
4. يُسجل العداد، ويُرسل رد إعادة التوجيه الفوري (HTTP 307 Temporary Redirect) نحو رابط الإحالة الرسمي للمتجر التابع مع كود العمولة المعتمد.

### ج. جلسات التوثيق وحماية الإدارة
1. **الجلسات المشفرة:** تُخزن بيانات جلسة المستخدم في كوكي موقّع يحتوي على معرف المستخدم وبريده وصلاحيته.
2. **فحص الصلاحيات الإدارية:** عند استدعاء أي مسار تحت `/admin` أو أي API إداري تحت `/api/admin`، يفحص الخادم البريد الإلكتروني ويطابقه حصراً مع قائمة `ADMIN_EMAILS` المحددة في بيئة الخادم المشفرة.
3. في حال عدم التطابق، يُرجع الخادم صفحة 404 بدون أي مؤشر على وجود شاشة إدارية.

## 4. نموذج البيانات المشترك (Data Models)

### أ. نموذج المنتج (Product Model)
* `id` و `slug`: المعرف الفريد ورابط السلاغ الصديق لمحركات البحث.
* `title`: العنوان باللغتين العربية والإنجليزية.
* `description`: الوصف والتحليل التحريري باللغتين.
* `whyWeChoseIt`: مبررات الاختيار والمميزات التنافسية.
* `flaws`: العيوب ونقاط الضعف بكل شفافية ومصداقية.
* `price`: السعر الرقمي والعملة (USD, MAD, SAR...).
* `pricePolicy`: سياسة عرض السعر (`show_with_timestamp` أو `hide_price_check_store`).
* `priceUpdatedAt`: الختم الزمني لآخر فحص للسعر.
* `source`: المتجر الشريك (`amazon`, `noon`, `temu`, `clickbank`).
* `affiliateUrl`: رابط الإحالة الرسمي التابع.
* `images`: مصفوفة روابط الصور المعتمدة.
* `status`: حالة النشر (`published` أو `draft`).
* `categorySlug`: تصنيف المنتج.

### ب. نموذج المتجر الشريك (Source Model)
* `id`: اسم المتجر (مثل amazon).
* `name`: الاسم المعروض.
* `disclosure`: نص الإفصاح القانوني المطلوب باللغتين العربية والإنجليزية.
* `pricePolicyDefault`: سياسة السعر الافتراضية المطبقة على منتجاته.
* `badgeColor`: لون الشارة البصرية المميزة للمتجر.
