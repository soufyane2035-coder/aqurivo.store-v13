# خطة التطوير الشاملة: استوديو تحويل الكود إلى صورة احترافية (AQURIVO Code-to-Image Studio)

- **الرابط في المنصة:** `/tools/code-to-image`
- **المكون البرمجي المستهدف:** `components/tools/CodeToImage.tsx`
- **القسم:** العمل والإنتاجية (`work`)
- **الحالة الحالية:** أداة بدائية جداً تعرض نص الكود باللون الأخضر فقط بدون تلوين للكلمات المفتاحية (No Syntax Highlighting)، ولا تسمح بتغيير الخلفية أو حجم الحواف أو إظهار أرقام الأسطر، وتعتمد على رسم نص خام بسيط في Canvas.

---

## 1. مرحلة البحث والمراجع العالمية (Role 1 — Researcher)

قمنا بدراسة أشهر 4 منصات عالمية يستخدمها المطورون وصناع المحتوى التقني يومياً:
1. **Ray.so (by Raycast):**
   - **ما يميزها:** البساطة الفائقة والخلفيات المتدرجة الفاخرة المصممة بعناية (Curated Gradients)، مع التحكم السريع في الحواف الداخلية (Padding: 16, 32, 64) والوضع الداكن/الفاتح للنافذة.
2. **Carbon.now.sh:**
   - **ما يميزها:** التحكم في نمط إطار النافذة (macOS Traffic Lights، نافذة Minimal، أو إطار هندسي حاد)، وإظهار/إخفاء أرقام الأسطر، وتلوين الكود البرمجي بدقة.
3. **Snappify & Chalk.ist:**
   - **ما يميزها:** إمكانية إضافة شارة سفلية أنيقة (Watermark / Author Handle / Language Badge) واختيار أبعاد الصورة المناسبة للنشر (تلقائي، 16:9، أو مربع لمنصات التواصل)، مع التصدير الفوري بدقة عالية `2x / Retina PNG` أو نسخ الصورة مباشرة إلى الحافظة (`Copy Image to Clipboard`).

## 2. الرؤية الاستراتيجية والهدف (Role 2 — Strategist)

- **من هو الزائر؟** مبرمج، كاتب تقني، طالب علوم حاسوب، أو صانع محتوى يريد مشاركة مقطع برمجي على X (تويتر)، LinkedIn، GitHub، المدونات، أو العروض التقديمية بمظهر بصري مبهر.
- **ما المشكلة الحقيقية التي نحلها؟** لقطات الشاشة العادية من محرر الأكواد تبدو باهتة وغير متناسقة الأبعاد، بينما الأدوات البدائية تعرض نصاً بلون واحد يفتقر للجاذبية والاحترافية.
- **القيمة الفريدة في AQURIVO:**
  1. **محرك تلوين ذكي للكود (Built-in Multi-Language Syntax Tokenizer):** يلون الكلمات المفتاحية (Keywords)، النصوص (Strings)، التعليقات (Comments)، الأرقام (Numbers)، والدوال (Functions) تلقائياً في المعاينة الحية وفي الصورة المصدّرة عاليـة الدقة!
  2. **ثيمات وخلفيات بهوية AQURIVO الفاخرة:** مجموعة منتقاة من الخلفيات المتدرجة وثيمات الكود (AQURIVO Emerald Noir، Midnight Gold، Cyber Ocean، Nord Aurora، Minimal Paper).
  3. **تصدير Retina PNG (2x) + نسخ الصورة مباشرة للحافظة (Clipboard Image Copy):** مع تحكم كامل في إطار النافذة، أرقام الأسطر، الحواف، واسم الملف.

## 3. هندسة تجربة المستخدم وهيكل الواجهة (Role 3 — UX Architect)

### أ) الشريط العلوي (Studio Header Bar):
- **شعار SVG خاص بالأداة:** أيقونة هندسية تمثل "نافذة كود برمجي محاطة بإطار عدسة تصوير ضوئية".
- **أمثلة أكواد جاهزة بنقرة (Code Presets):**
  1. *TypeScript / React Hook*
  2. *Python Data / AI Snippet*
  3. *SQL / API Query*
  4. *CSS / Architecture Tokens*
  5. *تفريغ المحرر لكتابة كودك الخاص*

### ب) شريط التحكم في التصميم (Studio Control Deck):
1. **اختيار الثيم والخلفية (Theme & Canvas Backdrop):**
   - 6 خلفيات وثيمات تلوين متكاملة (معاينة لونية فورية).
2. **إعدادات النافذة والكود:**
   - اللغة البرمجية (TypeScript/JS, Python, HTML/CSS, SQL, JSON, Go/Rust, Bash).
   - عنوان الملف في شريط النافذة (مثلاً: `aqurivo-engine.ts`).
   - نمط أزرار النافذة: (macOS ملون، macOS أحادي، هندسي، بدون شريط).
   - تفعيل/إخفاء أرقام الأسطر (`Line Numbers`).
   - حجم الحواف المحيطة (`Padding`: صغير `24px`، متوسط `48px`، واسع `72px`).
   - توقيع سفلي اختياري (مثلاً اسم المطور أو التخصص).

### ج) مساحة العمل والمعاينة الحية (Live Interactive Stage & Editor):
1. **المعاينة البصرية الحية (Live Syntax-Highlighted Preview Stage):**
   - تعرض النافذة البرمجية بتلوين كامل للكود، مع أرقام الأسطر، والظلال العميقة، والخلفية المختارة تماماً كما ستظهر في الصورة النهائية.
2. **محرر الكود السريع (Clean Code Input Area):**
   - منطقة إدخال وتعديل الكود مع دعم المسافات البادئة وعداد الأسطر والحروف.
3. **شريط التصدير الاحترافي (Export Action Bar):**
   - زر **"تحميل صورة عالية الدقة PNG (2x Retina)"**.
   - زر **"نسخ الصورة إلى الحافظة (Copy Image)"** للصقها مباشرة في المنشورات والمحادثات.
   - زر **"نسخ الكود النصي"**.

## 4. الهوية البصرية والشعار الخاص (Role 4 — Brand Designer)

- **الشعار الخاص (Custom SVG Emblem):**
  - أقواس برمجية `< / >` مدمجة داخل إطار كاميرا استوديو متوهج باللون الزمردي والسماوي.
- **نظام ألوان تلوين الكود (Syntax Palette):**
  - **الكلمات المفتاحية (`const`, `function`, `return`, `import`):** زمردي/سماوي مضيء.
  - **النصوص (`"..."`):** ذهبي كهرماني دافئ.
  - **الدوال والأنواع:** أرجواني/أزرق جليدي واضح.
  - **التعليقات (`// ...`):** رمادي متوازن هادئ.

- إشعار بصري أنيق على الزر عند نسخ الصورة للحافظة أو اكتمال التنزيل.

## 7. الخطة الهندسية والأمان (Roles 7 & 8 — Engineer & Security QA)

- **الملفات المستهدفة بعد موافقتك:**
  1. `components/tools/CodeToImage.tsx`
  2. `components/tools/CodeToImage.module.css`
  3. `lib/tools-data.ts`
- **ضوابط الدقة والأمان:**
  - بناء محلل الرموز البرمجية (Tokenizer) داخلياً بـ TypeScript النقي دون الاعتماد على مكتبات خارجية ثقيلة قد تبطئ الصفحة، مع مطابقة تامة بين ما يظهر في المعاينة الحية وما يُرسم على `HTML5 Canvas` بدقة `2x` عند التصدير.
  - دعم كامل للأسطر الطويلة (Auto Line Wrapping) ومنع خروج النص خارج إطار البطاقة، مع معالجة آمنة لأي رموز خاصة بدون استخدام `dangerouslySetInnerHTML`.
