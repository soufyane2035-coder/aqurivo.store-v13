# دليل الصفحة الرئيسية وتشريحها البرمجي (HOME_PAGE.md)

مرحباً بك يا صديقي في التوثيق المتعمق للصفحة الرئيسية لمنصة **AQURIVO**. يشرح هذا الملف كافة الجوانب المعمارية، المكونات التفاعلية، تدفق البيانات، وقائمة الأزرار وعناصر التحكم في هذه الصفحة الحيوية.

---

## 1. المسارات واللغات (Routes & Locales)
* **المسار الافتراضي (Root):** `/` (عبر `app/page.tsx`)
* **المسار متعدد اللغات (Localized):** `/[locale]` (عبر `app/[locale]/page.tsx` للغتين العربية `ar` والإنجليزية `en`)
* **الاتجاه اللغوي:** يدعم RTL تلقائياً مع اللغة العربية و LTR مع الإنجليزية عبر CSS Logical Properties و `dir` في وسم `<html>`.

---

## 2. ما هي وظيفة الصفحة الرئيسية؟ (ماذا تفعل؟)
1. **تقديم هوية AQURIVO الدافئة:** ترسيخ الانطباع الأول للمنصة كدليل مراجعات مستقل يركز على القيمة الحقيقية للمشتري بدلاً من الإعلانات الترويجية الصاخبة.
2. **عرض المنتجات المختارة تحريرياً (Editorial Curation):** إبراز باقة من أفضل المنتجات المختارة مع شارات المصدر والميزات والعيوب الشفافة.
3. **الوصول السريع للأدوات المالية التفاعلية (Smart Tools Pulse):** تقديم لمحة تفاعلية تحفز الزائر على استخدام الحاسبات المالية (مثل: هل يستحق الشراء، وحاسبة الفائدة المخفية).
4. **شريط الفئات والتصفية الفورية:** تمكين الزائر من استعراض المنتجات حسب مجاله المفضل بنقرة واحدة دون انتظار أو إعادة تحميل الصفحة.
5. **بناء الثقة ومراجعات الزوار:** عرض شهادات حقيقية ورسائل توضح الشفافية في نموذج العمولة وإفصاح الشركاء.

| الملف | النوع | المسؤولية والدور البرمجي |
| :--- | :--- | :--- |
| `app/page.tsx` | Server Component | نقطة الدخول الافتراضية؛ يقرأ لغة المستخدم ويسترجع البيانات من الكاش. |
| `app/[locale]/page.tsx` | Server Component | نقطة الدخول المحددة باللغة (`ar` أو `en`)، يولد وسوم الـ Metadata وبيانات الـ SEO المنظمة. |
| `components/sections/HomeClient.tsx` | Client Component | يدير الحالة التفاعلية في الواجهة (تحديد الفئة النشطة، تصفية المنتجات في الذاكرة، والتفاعل مع المفضلة). |
| `components/sections/HeroSection.tsx` | Server Component / UI | يقدم قسم البطل (Hero Section): العنوان التحريري، الوصف الدافئ، وأزرار الحث على الإجراء (CTAs). |
| `components/sections/HeroSection.module.css` | CSS Module | أنماط وتنسيقات قسم الهيرو المعتمدة على المتغيرات التصميمية (Tokens) بدون Tailwind. |
| `components/sections/SiteHeader.tsx` | Client Component | الترويسة العلوية الثابتة: الشعار، روابط التنقل، مبدل اللغة، مبدل المظهر (Dark/Light)، وزر المفضلة السريع. |
| `components/sections/SiteFooter.tsx` | Server Component | التذييل الشامل: روابط الأقسام، الصفحات القانونية، إفصاح العمولة، وسائل التواصل، وبيانات الاتصال الرسمية. |
| `components/SmartToolPulse/SmartToolPulse.tsx` | Client Component | شريط عائم تفاعلي يعرض لمحات من الأدوات المالية الذكية. |
| `components/ui/ProductCard.tsx` | Client Component | بطاقة المنتج الفردية: عرض الصورة، السعر، المتجر، زر الشراء، وزر الحفظ. |
| `components/Testimonials/TestimonialsSection.tsx` | Server Component | قسم آراء ومراجعات وتجارب الزوار الحقيقية. |

| `lib/cache/categories-cache.ts` | Server Cache | طبقة التخزين المؤقت للفئات المعتمدة. |

## 4. كيف تعمل الصفحة في الكواليس؟ (Lifecycle & Data Flow)

1. **الطلب الأولي (Incoming Request):** عندما يتصفح الزائر `/`، يقوم Next.js بقراءة `locale` عبر معايير الرابط أو الكوكي.
2. **استرجاع البيانات المخبأة (Cache Retrieval):** يستدعي الخادم `productsCache.getPublished()` لاسترجاع قائمة المنتجات المنشورة فوراً من الذاكرة العشوائية دون استدعاء بطيء لقاعدة البيانات.
3. **تجهيز وسوم السيو (SEO & Metadata Generation):** تُنشئ دالة `generateMetadata` وسوم الـ Title و Description و Canonical URL و OpenGraph باللغة المناسبة، إضافة إلى بطاقة `ItemList` المنظمة لمحركات البحث.
4. **التصيير على الخادم (SSR / Static Rendering):** تُرسل الصفحة كـ HTML مكتمل فائق السرعة، مما يمنح الزائر سرعة عرض فورية (First Contentful Paint بأقل من 300ms).
5. **تنشيط التفاعل في المتصفح (Hydration):** يتولى المكوّن `HomeClient.tsx` إدارة التفاعلات المحلية مثل تغيير الفئة الحالية والتحقق من المنتجات المحفوظة في `localStorage`.

## 5. فهرس الأزرار والتفاعلات بالتفصيل وماذا تفعل

### أ. أزرار الترويسة العلوية (Site Header)
* **شعار AQURIVO:**
  * *الحدث:* النقر على الشعار أو النص.
  * *المصير والنتيجة:* العودة الفورية للصفحة الرئيسية `/` أو `/[locale]`.
* **روابط التنقل الرئيسية (المنتجات، الأدوات، الأقسام، الأدلة، من نحن):**
  * *الحدث:* النقر على أي رابط.
  * *المصير والنتيجة:* انتقال انسيابي للصفحة المعنية مع إبراز الرابط النشط بصرياً.
* **زر تبديل اللغة (العربية / English):**
  * *الحدث:* النقر على محدد اللغة.
  * *المصير والنتيجة:* تبديل لغة الواجهة فورياً مع الاحتفاظ بالمسار الحالي وتغيير اتجاه الصفحة (`rtl` أو `ltr`).
* **زر تبديل المظهر (Dark / Light Mode):**
  * *الحدث:* النقر على أيقونة الشمس/القمر.
  * *المصير والنتيجة:* تبديل متغيرات الألوان الجذرية في `tokens.css` بسلاسة تامة، مع حفظ تفضيل الزائر في `localStorage`.
* **أيقونة المفضلة والمحفوظات (المختارات المحفوظة):**
  * *الحدث:* النقر على أيقونة الحقيبة / القلب.
  * *المصير والنتيجة:* الانتقال لصفحة `/account` لعرض قائمة المنتجات المحفوظة، مع وجود عداد رقمي يوضح كم منتجاً حفظه الزائر.

### ب. أزرار قسم البطل (Hero Section)
* **زر «استكشف التوصيات المختارة» (Primary CTA):**
  * *الحدث:* النقر على الزر الرئيسي.
  * *المصير والنتيجة:* تحريك الصفحة بانسيابية (Smooth Scroll) نحو قسم شبكة المنتجات في الأسفل لتسهيل التصفح الفوري.
* **زر «الأدوات الذكية وحاسبات الشراء» (Secondary CTA):**
  * *الحدث:* النقر على الزر الثانوي.
  * *المصير والنتيجة:* التوجه مباشرة إلى فهرس الأدوات المالية التفاعلية `/tools`.

### ج. أزرار شريط الفئات (Category Tabs)
* **تبويب «الكل» (All):**
  * *الحدث:* النقر على تبويب الكل.
  * *المصير والنتيجة:* إعادة ضبط حالة التصفية لعرض جميع المنتجات المنشورة بدون قيد.
* **تبويبات الفئات المتخصصة (إلكترونيات العمل، أدوات القهوة، وغيرها):**
  * *الحدث:* النقر على أي تبويب فئة.
  * *المصير والنتيجة:* تصفية قائمة المنتجات المعروضة فورياً في الواجهة دون وميض أو إعادة تحميل، وتنشيط المظهر البصري للتبويب المحدد.

### د. أزرار بطاقة المنتج (Product Card)
* **زر «حفظ في المفضلة» (أيقونة القلب/العلامة):**
  * *الحدث:* النقر على الأيقونة.
  * *المصير والنتيجة:* إضافة معرف المنتج لمصفوفة المحفوظات في `localStorage` (وتحديث عداد الترويسة)، أو إزالته إن كان مضافاً مسبقاً، مع إظهار Toast توضيحي لطيف.
* **صورة المنتج أو عنوانه:**
  * *الحدث:* النقر على بطاقة المنتج أو عنوانه.
  * *المصير والنتيجة:* الانتقال لصفحة التفاصيل المعمقة للمنتج `/products/[slug]`.
* **زر «اشترِ من [أمازون / نون / تيمو]» (Buy Now CTA):**
  * *الحدث:* النقر على زر الشراء.
  * *المصير والنتيجة:* فتح نافذة المتجر الرسمي في لسان تبويب جديد عبر مسار الإحالة الآمن المشفر `/go/[slug]`، مع تسجيل النقرة في إحصائيات الخادم وإرفاق كود العمولة الصحيح.
